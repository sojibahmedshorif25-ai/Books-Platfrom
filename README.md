# 📚 Book Borrowing Platform

Online book borrowing web application built with Next.js

## 🚀 Features

- ✅ User Authentication (Register & Login)
- ✅ Browse and Search Books
- ✅ Filter by Category (Story, Tech, Science)
- ✅ View Book Details
- ✅ Borrow Books
- ✅ User Profile Management
- ✅ Responsive Design

## 🛠️ Tech Stack

- Next.js 16
- TypeScript
- Tailwind CSS
- DaisyUI
- React Hot Toast
- Swiper.js

## 📦 Installation

```bash
npm install
npm run dev
```

Open http://localhost:3000

## 📝 NPM Packages Used

- next

- daisyui

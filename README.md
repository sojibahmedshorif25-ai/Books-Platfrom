## 📖 Overview

**Borrowly** is an online book borrowing platform built with Next.js 16. Users can browse, search, and borrow books with a beautiful responsive interface featuring Swiper carousels and Marquee animations.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🔐 **Authentication** | Secure user login with better-auth |
| 📖 **Book Catalog** | Browse all available books |
| 🔍 **Search** | Find books by title |
| 🏷️ **Category Filter** | Story, Tech, Science categories |
| 📄 **Book Details** | Detailed book information |
| 📚 **Borrowing** | Borrow books easily |
| 👤 **User Profile** | Manage your account |
| 🎠 **Swiper Carousel** | Touch-enabled carousels |
| 📢 **Marquee** | Animated scrolling text |
| 📱 **Responsive** | Works on all devices |

| Technology | Purpose |
